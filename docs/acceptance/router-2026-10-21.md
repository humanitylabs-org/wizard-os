# Connection Router acceptance: Claude only, ChatGPT only, both, neither (21 Oct 2026)

The Connection Router picks which AI model serves each app feature (DECISIONS #65, [CONNECTION_ROUTER.md](../../spec/CONNECTION_ROUTER.md)). This run checks the last open line of that section of `WORK_OUTSTANDING.md`: does an owner's app get the right model, or a clear request to act, whichever AI subscriptions the box has? Run by Archimedes, Kanban task `t_00a3470e`.

**Result: all four states behave as the spec says (48 of 48 checks pass).** Nothing swapped silently. A feature tested on one model ran on that model when its provider was connected. Otherwise it waited for the owner, who saw a named replacement to approve or a Connect button. The one defect found is wording: Wisdom told the owner "Connect a model to use Ask AI" when *Look up* was the feature refused. The fix is [wisdom #34](https://github.com/humanitylabs-org/wisdom/pull/34).

## What an owner sees

- **Claude only.** Wisdom is ready straight away. Ask AI, Look up and Chapter authoring each run on the exact Claude model they were tested on. The test app's ChatGPT-tested feature asks the owner to approve Claude Sonnet 5 instead, or to connect ChatGPT.
- **ChatGPT only.** Wisdom installs and opens. Its install sheet says two features need a model. Look up offers "Approve swap" to `gpt-6-luna`. Once the owner taps it, Look up answers on `gpt-6-luna`, labelled "approved swap, results may differ". Ask AI offers only "Connect Claude", because ChatGPT has no standard-tier model. Chapter authoring is marked "Off until connected": it is `swap: never`, so it only ever runs on `claude-opus-5-5`.
- **Both.** Every Wisdom feature runs on its tested Claude model, and the test app's ChatGPT-tested feature runs on ChatGPT. Provider order decides the suggestion for a model neither provider has. ChatGPT first suggests `gpt-6-luna`; Claude first suggests `claude-haiku-4-5`. Changing the order changes `GET /v1/owner/routes` and the sheet. It never moves a feature off a model that matches.
- **Neither.** The sheet shows only Connect buttons. Every run is refused with a plain reason and a link to the Router's page (`/wizard-os-home/?open=wizard-connection-router`). Wisdom still installs and opens (HTTP 200).
